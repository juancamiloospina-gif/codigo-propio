# Plan: IP Vault

## Resultado
Construir una aplicación web completa y responsive para auditar dependencia SaaS, simular la creación de una plataforma propia y presentar una bóveda temporal de código.

## Implementación
- Crear un sistema visual cyber-fintech oscuro con fondo zinc/slate, acentos esmeralda y cyan, vidrio sutil, bordes luminosos y tipografía técnica.
- Reemplazar la portada vacía por un flujo único con navegación fija, introducción compacta y entrada de dominio.
- Implementar la calculadora TCO con selección múltiple de herramientas, controles de usuarios/años y métricas recalculadas en tiempo real.
- Implementar el simulador con terminal animada y un dashboard interactivo personalizado con el dominio introducido.
- Implementar IP Vault con contador regresivo funcional, explorador Git interactivo, estado bloqueado y CTA final.
- Añadir transiciones suaves, estados accesibles y adaptación completa a móvil y escritorio.
- Incorporar metadatos propios de IP Vault y validar visualmente el flujo principal.

## Alcance técnico
- React con estado local para el wizard, cálculos, terminal, pestañas, árbol y reloj.
- Tailwind CSS v4 con colores y efectos definidos como tokens semánticos globales.
- Lucide para iconografía y componentes reutilizables para controles y botones.
- Sin servicios externos ni persistencia: esta entrega es una experiencia funcional de demostración en el navegador.
