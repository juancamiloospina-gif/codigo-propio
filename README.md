# Code Sovereignty Hub

Actúa como un desarrollador Senior Full-Stack experto en React, Tailwind CSS, Lucide Icons y Shadcn UI. Construye la aplicación web completa para "IP Vault" (Protocolo de Liberación de Código y Soberanía Tecnológica).

DISEÑO Y ESTÉTICA GENERAL:

- Dark mode elegante de grado cibernético/fintech: Fondo oscuro Slate/Zinc (#080C14 y #0F172A), acentos verdes Neón/Esmeralda (#10B981) y Cyan (#06B6D4), bordes con sutil brillo brillante (glow effect) y tarjetas de vidrio (glassmorphism).

- Tipografía moderna e interfaces densas en información pero altamente pulidas.

ESTRUSTURA DE LA APLICACIÓN (Vista Principal en un solo flujo o Multi-Step Wizard):

1. HEADER / NAVBAR:

- Logo: "IP Vault" con ícono de escudo o candado abierto glowing.

- Badge en vivo: "Agentes de Análisis Activos" con un punto verde intermitente.

- Menú sencillo: "Calculadora de Riesgo", "Simulador", "Soberanía IP", botón CTA "Ver Demo".

2. HERO SECTION COMPACTO:

- Título principal: "Reclama la propiedad de tu código. Elimina el alquiler SaaS."

- Subtítulo: "Analiza el costo de dependencia de tu empresa, simula la creación de tu sistema propio y libera tu repositorio Git."

- Input de entrada interactivo: "Dominio de tu empresa (ej. acme.com)" + Botón "Iniciar Auditoría Tecnológica".

3. PASO 1: AUDITORÍA Y CALCULADORA TCO (Costo Total de Propiedad):

- Selección multi-opción de herramientas SaaS actuales: Salesforce, HubSpot, Zendesk, SAP, Jira, ERP Propietario, Custom SaaS.

- Sliders dinámicos: 

  * "Número de usuarios activos" (1 a 1,000)

  * "Años operando con estas herramientas" (1 a 10)

- Métrica dinámica en tiempo real:

  * Gasto estimado acumulado a 5 años ($ USD)

  * Índice de Soberanía IP (0% al 100% - resaltado en rojo si es bajo)

  * Costo proyectado de migración a arquitectura propia (con ahorro del >60% a largo plazo).

- CTA: "Generar Prototipo de Código Fuente Propietario".

4. PASO 2: SIMULADOR DE "HACKATHON DE CÓDIGO EN VIVO":

- Ventana tipo terminal de comandos con logs animados simulados:

  * [0.1s] Extrayendo assets de marca del dominio...

  * [0.8s] Eliminando dependencias de código propietario de terceros...

  * [1.5s] Generando arquitectura limpia (React, Node.js, PostgreSQL, Docker)...

  * [2.2s] Desplegando sandbox seguro en infraestructura aislada...

- Al terminar los logs, renderiza un Dashboard Mockup interactivo funcional adaptado a la marca introducida con pestañas: "Panel Operativo", "Gestión de Usuarios", "Módulo de Métricas", y "Conectores de API".

5. PASO 3: MÓDULO "THE IP VAULT" (La Bóveda de Código):

- Tarjeta principal destacada con borde Glowing Verde/Cyan.

- Contador digital gigantesco regresivo comenzando en 71:59:59 (reloj funcional).

- Previsualización interactiva de estructura de árbol de código Git (/src, /config, /docker, /database, /tests).

- Banner de alerta: "ESTADO: BÓVEDA RESERVADA Y BLOQUEADA".

- Mensaje: "Este repositorio con el código base de tu empresa se autodestruirá cuando el contador llegue a cero para garantizar la privacidad de tus datos."

- CTA Principal: "Desbloquear Código Fuente y Agendar Sesión de Arquitectura".

Asegúrate de que toda la experiencia sea fluida, con transiciones suaves entre componentes, widgets completamente interactivos y respuesta 100% adaptativa (responsive).
